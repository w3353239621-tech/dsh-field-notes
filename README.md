# dsh-field-notes · DSH 踩坑卡

在 Windows 上把 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）当日常工具用了一个月，
把**真踩过、且复发过**的坑写成卡片。**25 张卡，全部来自实际报错。**

每张卡里只有四样东西：什么时候会撞上（触发）、可直接复制的做法（首选）、试过不通的路（别再走）、怎么确认真成了（验证）。

> 📦 **这是一份个人云存档。** 卡片跟着作者自己的踩坑继续追加，但不承诺跟进 DSH 版本变化，issue 不保证回应 —— 拿去当模板自己维护，比等更新实在。

## 这份笔记解决什么

DSH 这类「Agent 桌面端 + 插件系统 + 沙箱」的软件，卡点往往不在概念，而在**具体报错原文**
——`ambiguous-install`、`stale-approval`、`SessionStateUnauthorizedAccessException`、
`only core types are allowed` …… 搜不到，问模型也是泛泛而谈。这份笔记按**报错原文和现象词**组织，
目的是一搜就到。

## 怎么用

**按现象搜，不要按目录翻。** 卡的第一块永远是：

```
> **触发**：任务里会出现的说法（用你会说的话写）
> **锚点**：会原样出现的字 —— 域名 / 命令名 / 扩展名 / 报错原文
```

所以检索方式是拿任务里的**现象词**去 grep 锚点行：

```bash
grep -il "锚点.*install_bundle" cards/*.md     # 例：插件装不上
grep -il "锚点.*utf-8 bom" cards/*.md          # 例：PowerShell 中文乱码
grep -il "锚点.*413" cards/*.md                # 例：下载大文件被挡
```

Windows 上没有 grep 就用 `Select-String -Path cards\*.md -Pattern "锚点.*<现象词>"`。

## 卡片分类

文件名前缀就是分类，列目录一眼能分开：

| 前缀 | 覆盖 |
| --- | --- |
| `工具-` | 环境与依赖：装插件、桌面端启动、会话/配置、性能、asar |
| `脚本-` | 命令行与编码：PowerShell 陷阱、沙箱管道、token 统计、大文件下载 |
| `模型-` | 模型行为：读图与像素、推理挡位、渠道与鉴权、比价 |
| `抓取-` | 网页/接口正文抓不到 |
| `文件-` | 工作区外写不进去、PPTX 排版与渲染 |
| `网络-` | 桥接与远程访问 |
| `游戏-` | 崩溃与 Steam 报错取证 |
| `任务-` `OCG策略缓存-` | 长任务阶段交付、嵌套子进程改写 owner |

## 几条代表性的

- `工具-DSH装插件后崩或插件消失`：插件把 `@deepseek-ai/dsh-*` 写进 `dependencies` → lock 钉死旧核心包 → profile 根被 hoist 回旧版，整个插件页空掉。怎么用时间戳定位被 hoist 的包。
- `脚本-PowerShell中文与参数陷阱`：`param([string]$Pid)` 撞只读自动变量导致整个函数返回空；heredoc 里 4 个连续单引号被解析成 `'''`+`'`。
- `模型-模型自己OCR读图而没拿到像素`：模型说"我看到了图"，其实拿的是文字摘要——附判据。
- `工具-读asar别用grep`：asar 里的 JS 用文本工具搜不全，要先解出来。

## 写卡规则

在 `docs/template.md`。核心三条：

1. **目标是 ≤ 2 KB**。这是工具流，不是复盘报告。
2. **只写复发过的坑**（或代价极大的第一次）。
3. **锚点行只写会原样出现的字**：中文描述放触发行，锚点写英文/符号/报错原文——否则 grep 命中不了。

## 环境

这些卡是在 **Windows 11 + DSH 桌面端（0.2.x）** 上踩出来的：路径写法、沙箱行为、PowerShell 5.1 与
pwsh 的差异都带 Windows 假设。Linux/macOS 上大部分「现象」仍然成立，但具体命令要换。
