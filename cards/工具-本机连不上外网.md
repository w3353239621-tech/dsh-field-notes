# 工具-本机连不上外网（curl / git 报错）

> **触发**：想从 GitHub 下东西，curl 报 schannel、git clone 报管道、pwsh 抓取超时；而网页抓取工具却正常
> **锚点**：`curl`、`schannel`、`SEC_E_NO_CREDENTIALS`、`git clone`、`remote-https`、`Permission denied`、`web_fetch`
> **验证**：`node -e "fetch('<url>').then(r=>r.text()).then(t=>console.log(t.length))"` 打出真实字节数（不是 0、不是报错）

## 首选

bash 里用 DSH 自带 node 下载 —— Node 自带 CA、不走 schannel、不开子进程管道：

```bash
NODE="%USERPROFILE%/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe"
"$NODE" -e "const fs=require('fs');fetch('<tarball>').then(r=>r.arrayBuffer()).then(b=>fs.writeFileSync('repo.tar.gz',Buffer.from(b)))"
tar -xzf repo.tar.gz
```

单文件也行：MCP `web_fetch` 抓 `raw.githubusercontent.com`，正文直接落盘。

## 被挡时

- 整仓库：`https://codeload.github.com/<owner>/<repo>/tar.gz/refs/heads/main`
- 只需要读：MCP web_search / web_fetch（跑在宿主进程里，不受本地沙箱限制）。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| `curl -sSL <url>` | `curl: (35) schannel: AcquireCredentialsHandle failed: SEC_E_NO_CREDENTIALS (0x8009030e)` |
| `git clone https://github.com/...` | `error: cannot create standard input pipe for remote-https: Permission denied` |
| pwsh `Invoke-WebRequest` | `HttpClient.Timeout of 25 seconds elapsing`，无输出 |

## 注意

- 不是「没网」：同一个 bash 里 node 能下。**是 curl 借系统证书库被拦、git 需要开子进程管道被拦。**
- 别去调 `chcp`、代理变量、git 配置 —— 换工具比换参数快。

证据：2026-10-25 本会话，38 KB tarball 用 node 一次成功
