# 模型-推理挡位与鉴权

> **触发**：想知道某模型「思考强度」到底发没发、挡位差多少、能不能连官方 API；或换挡位后报 `UNSUPPORTED_REASONING_EFFORT`
> **锚点**：`reasoning_effort`、`thinking`、`reasoningEffort`、`chat/completions`、`/anthropic/v1/messages`、`qianfan.baidubce.com`、`401`、`api key `
> **验证**：抓 onPayload 看到真实 wire 字段，或读原始 `usage.completion_tokens_details.reasoning_tokens`

## 首选

- 挡位只认 `reasoning_effort`；`thinking:{type:"enabled"}` 只是**开关**，不是 high。
- 千帆：`supportsReasoningEffort: true` + `reasoningEfforts:{off:null,low:low,medium:medium,high:high,max:max}`；wire 由 pi-ai `thinkingFormat==="deepseek"` 发出（`dist/api/openai-completions.js:667-678`）。
- 要报思考量：读原始 API 的 `usage.completion_tokens_details.reasoning_tokens`，别经 pi-ai 归一化。
- 官方 API 是 **Anthropic Messages**：`POST https://api.deepseek.com/anthropic/v1/messages`，头 `anthropic-version: 2023-06-01`，按 SSE 解。

## 别再来

| 弯路 | 为什么不通 |
| --- | --- |
| 拿 DSH 登录 grant token 当 API key | `GET /v1/models` 返 401 `api key ****xxxx is invalid`；官方要单独 `sk-…` |
| 用 `usage.output` 当思考量 | 它已含 reasoning（`completion_tokens` 本身含），两口径差 1.5–4 倍 |
| 千帆用 `xhigh` 当顶格 | 实测反而更低；顶格是 `max` |
| 挡位用简单题测 | 各档都 30–90 token，拉不开；必须 5 难题×3 次取均值 |
| `max_tokens: 8192` | 长思考被截成 `finish_reason=length`；用 32768 |
| 千帆偶发 `400 invalid_argument` 就重建会话 | 同一条历史下一轮原样重发就能过；重建等于丢上下文。只有同一点连撞三次才值得换模型 |
| 给 provider 设默认档 `reasoning: <level>` 而不拆模型 | 无该挡位的模型（GLM 等）一选就抛 `UNSUPPORTED_REASONING_EFFORT` |

## 注意

- 默认档只在 `reasoningEfforts` 覆盖后可靠；`getSupportedThinkingLevels()` 对没写的模型只返回 `["off"]`（`lib/index.js:771-779`、`:1785-1789`）。
- 千帆「不传参数」实测比 high 输出还多约 11%，属隐藏高档。
- 解包 app.asar 跑 pi-ai `stream()`：fake model 要给全 `cost:{input:0,output:0,cacheRead:0,cacheWrite:0}`（否则 `model.cost.tiers` 报错）、`baseURL` 与 `baseUrl` 都写、别 import 整个 `dist/index.js`。
